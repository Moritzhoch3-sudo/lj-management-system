# 🚀 Anleitung: Landjugend Aufgabentool kostenlos online stellen (Option A)

Mit dieser Anleitung stellst du dein Aufgabentool so bereit, dass alle Mitglieder der Vorstandschaft von überall (auch unterwegs per mobilen Daten) darauf zugreifen und Aufgaben synchron verwalten können.

---

## Methode 1: Über Vercel (Kostenlos, Schnellste Methode ⭐)

1. **Kostenloses Vercel-Konto erstellen:**
   - Gehe auf [vercel.com](https://vercel.com) und erstelle dir einen kostenlosen Account (z. B. per E-Mail oder GitHub).

2. **App hochladen:**
   - **Option A (Ohne Git/GitHub):**
     1. Installiere das Vercel CLI im Terminal: `npm i -g vercel`
     2. Navigiere im Terminal in den Ordner `lj-management-system`.
     3. Tippe `vercel` ein und folge den einfachen Anweisungen auf dem Bildschirm.
   - **Option B (Mit GitHub - Empfohlen für automatische Updates):**
     1. Erstelle ein neues Repository auf [github.com](https://github.com).
     2. Lade den Ordner `lj-management-system` auf GitHub hoch.
     3. Verbinde dein GitHub-Konto auf [vercel.com/new](https://vercel.com/new) und wähle das Repository aus.
     4. Klicke auf **Deploy**.

3. **Fertig!**
   Du erhältst sofort deine eigene Web-Adresse (z. B. `https://lj-scheuring-tasks.vercel.app`), die du direkt an den Vorstand schicken kannst.

---

## Methode 2: Über Netlify (Drag & Drop – Ohne Terminal)

1. Gehe auf [netlify.com](https://www.netlify.com/) und erstelle einen kostenlosen Account.
2. Gehe im Dashboard auf **Sites** -> **Add new site** -> **Deploy manually**.
3. Ziehe den gesamten Ordner `lj-management-system` per Drag & Drop in das Fenster.
4. Netlify erstellt in 5 Sekunden deinen fertigen Online-Link!

---

## 🔒 Echtzeit-Synchronisation & Sicherheit

- **Zentraler Cloud-Sync:** Alle Aufgaben, Finanzen und Protokolle werden automatisch live zwischen allen Vorstandskollegen synchronisiert.
- **Passwort- & PIN-Schutz:** Der Zugriff auf vertrauliche Bereiche (Kassenbuch, Verträge) bleibt durch deinen Master-PIN geschützt.
